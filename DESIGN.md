# Velo design direction

## Product read

Velo is a public record for a market call with a real position behind it. The first surface serves a curious visitor who needs to understand the product and trust its truth model before connecting a wallet.

## Visual thesis

An editorial ledger for live conviction. The main object is a Call, shown as a record with a state that can change. The page uses open space, ruled boundaries, and a single chartreuse signal so the product feels accountable rather than promotional.

## System

- Surface: matte near-black, with a subtle monochrome grain layer.
- Text: warm off-white for primary content, muted gray for context.
- Accent: chartreuse marks live state and the primary action.
- Semantic color: reserved for future higher or lower result states.
- Type: IBM Plex Sans for interface copy, DM Mono for timestamps and proof metadata, Georgia italic for the editorial emphasis.
- Shape: 8px radii, thin rules, flat sections, no repeated glass cards.
- Rhythm: large vertical section spacing, asymmetric editorial splits, strong left edge alignment.

## Interaction

The shell has one primary path, Make a call, which moves to Live. Wallet buttons expose a truthful integration status until the real DreamDEX connection is available. Reduced motion removes transitions and smooth scrolling.

## Truth constraints

No market names, prices, probabilities, usernames, calls, receipts, follower counts, accuracy, or performance metrics are invented in the product shell.
